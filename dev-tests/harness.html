                Bio
                Grist Factory conçoit des widgets libres pour Grist. Dashboard BI en est un : croiser vos données Grist dans des tableaux de bord multi-tuiles avec cross-filtering et drill-down, directement dans Grist.

                Mots-clés des publications

                Remplit une colonne de mots-clés à partir du texte de chaque publication, lu dans votre navigateur : rien n’est envoyé ailleurs. Une cellule déjà remplie n’est jamais modifiée.

                Connectez d’abord une table de travail (menu Données).

                D’où vient le texte ?

                Demande l’extension « Mots-clés des PDF » de Grist Factory Suite.

                Ces mots ne sont pas répétés dans la colonne automatique.

                    Importer un fichier Power BI

                    Lit les visuels d'un fichier .pbix ou .pbit (type de graphique, colonnes utilisées, titre) et propose des tuiles correspondantes sur la table de travail actuelle. Les données du fichier Power BI ne sont pas importées par ce chemin.

                    Pour les vraies données du fichier (pas seulement sa mise en page) : exportez-les depuis Power BI (clic droit sur un visuel → « Exporter les données », ou « Analyser dans Excel »), puis déposez le CSV obtenu ci-dessous — ou importez-le via l'import natif de Grist. Les tuiles ci-dessus retrouveront alors les bonnes colonnes.

                      Données (CSV exporté de Power BI)

                      Déposez ici le CSV exporté depuis Power BI (clic droit sur un visuel → « Exporter les données », ou « Analyser dans Excel » puis enregistrement en CSV). Le widget détecte les colonnes et leur type et vous montre un aperçu ; la table n'est créée dans votre document Grist qu'après votre confirmation explicite.

                        La bibliothèque de graphiques (ECharts, js/vendor/echarts/echarts.min.js) n'a pas pu être chargée : les cartes KPI fonctionnent, mais les tuiles barres/camembert resteront vides. Ouvrez la console du navigateur (F12 → Console / Réseau) pour voir pourquoi.

                        Ce rapport vous est partagé en lecture seule : Grist refuse d'enregistrer vos modifications. Demandez l'accès en écriture à son propriétaire, ou travaillez sur une copie.

                        Pour commencer

                        Des visualisations adaptées à vos données : un clic suffit, vous pourrez les modifier ensuite.

                          Aucune tuile pour l'instant. Utilisez « Ajouter une visualisation » pour en créer une. Cliquer sur une barre/part filtre les autres tuiles (cumulable entre colonnes différentes ; recliquer retire le filtre). Une tuile avec un « Drill-down » se détaille au clic ; une carte KPI avec une « Tendance vs » affiche l'évolution par rapport à la période précédente. Ce tableau de bord est vide. Cliquez sur « Modifier » pour ajouter une visualisation.

                          Ajouter une visualisation

                          Quelle question voulez-vous poser à vos données ?

                                        Vide = automatique. Indicatif : les bornes sont arrondies à des valeurs simples (2, 5, 10…).

                                          Une colonne d'objectifs est agrégée comme la mesure et prend le pas sur la valeur saisie.

                                            Cochez les colonnes ; les flèches changent leur ordre.

                                            Une ligne vide sépare les paragraphes. « # » pour un titre, « - » pour une liste, **gras**. Le HTML n'est pas interprété.

                                            Aperçu

                                            Complétez les champs obligatoires pour voir l'aperçu.

                                            Options avancées

                                                      Un dégradé d'une seule teinte : clair = petite valeur, foncé = grande. « Standard » et « Okabe-Ito » donnent le bleu.
